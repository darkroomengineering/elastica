01 — Ref decode

What each reference is actually doing, mechanically.

Ref A — packed exclusion→ Footer
The magic isn't just the negative space — it's that every element is oriented: the eyes point along the packing flow, like iron filings around a magnet. No SDF support (circles + rects only) — so the inner shape is a compound of static bodies: either the wordmark built from static rects (one per letter stem, ~30–40 rects) or a silhouette traced by a ring of small static circles. Particles are plain circle bodies for collision; the rendered sprite on each is an oriented lozenge whose angle we set in the draw pass (angle ← velocity or field tangent) — orientation is visual, collision stays circular. Cheap and honest. mechanic: inward attraction + static rect/circle compound as the "shape" · circle collision + sprite rotation from velocity dir · 2–3 radii for tight packing
Ref B — magnetic type→ Hero
Key observation in the ref: letters overlap and interlock. Our collision boxes are fixed, so no interpenetration — and that's fine: with strong attraction + near-zero restitution the letters pack into a tight jostling knot instead of interlocking. Reads the same at speed; arguably better (the knot has visible tension). Two cheats if we want it closer: collision box slightly smaller than the glyph (boxes touch, glyphs kiss/overlap a few px), and free OBB rotation so the knot tumbles. mechanic: cursor attraction + restitution ≈ 0 · hitbox at ~85% of glyph for visual overlap · free OBB rotation · home springs on release
Ref C — big rolling glyphs→ Interstitials
Big, few, characterful. A band where oversized parenthesized glyphs — (n), (2D), (60fps), (MIT) — roll in from the left, bounce off whatever's already there, and pile against the right wall. 4–6 bodies, giant hit-areas, nearly free to simulate — perfect filler between S2/S3. They roll with real angular velocity, so entry speed comes from scroll velocity: scroll fast and they cannonball in. mechanic: circle bodies + OBB glyph render · spawn vx from Lenis velocity · right wall rigid, left periodic
Ref D — word-swarm cursor→ Text sections
The cursor isn't a dot — it's a cloud of small words stolen from the copy. As you move through the murmur section, the cursor picks up little words (the, of, and, is) which swarm around it; dwell and they drift back into their sentences. This merges beautifully with S3: the flock and the cursor-swarm are the same system at two scales — and it solves "cursor as body" with personality. mechanic: proximity steal (small words only, ≤4 chars) · noisy orbit around pointer · return spring on dwell · cap ~25 words

The Pop — media that fights for space.

The showcase moment — real images/icons (sites built with it, library glyphs, whatever we feature). Media pops in at scroll milestones: spawns at 0% scale and inflates as a live collision body, physically displacing everything already settled. The gallery never reflows on a grid — it negotiates. Later arrivals wedge in, early ones get shoved and tilted. End state is a jostled, packed shelf you can drag around.

This is the DOM-mode flex: each body is a real <img> — hoverable, clickable, draggable. Cap at ~20 items, well inside the 100-body law.

mechanic: scale-up = growing collision radius (displayScale + bounds sync) · spawn tied to scroll milestones · OBB, high friction, low restitution — it should feel like packing a suitcase, not a ball pit
